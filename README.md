# أثري — Teacher Portfolio

نسخة أولية احترافية قابلة للتوسع لمنصة توثيق الأعمال المهنية للمعلمين.

## ما تم بناؤه
- واجهة RTL عربية حديثة.
- هوية المعلم والمدرسة ورقم المدرسة 9037.
- أدوار: معلم، مرشد، إداري، Super Admin (محاكاة تبديل الدور في النسخة التجريبية).
- Dashboard، بوابات الأعمال، معرض الأعمال، صفحة المعلمين، مساعد AI، الإنجازات، الإعدادات.
- تجربة توثيق عمل جديدة مع واجهة تحليل صورة بالذكاء الاصطناعي.
- إشعارات وتجربة إدارة المدرسة بشكل تجريبي.
- تصميم Responsive.

## الخطوة التالية
ربط Supabase Auth + Database + Storage + RLS، ثم توصيل AI Vision وNotifications الحقيقية.
