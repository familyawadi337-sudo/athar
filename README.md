# أثري — Teacher Portfolio

واجهة عربية RTL لتوثيق الأثر المهني للمعلمين.

## المصادقة الحقيقية
أضيفت صفحة تسجيل دخول بالبريد الإلكتروني وكلمة المرور عبر Supabase Auth، وحماية للمسارات بجلسة محفوظة في cookies، وزر تسجيل خروج. لا يوجد إنشاء حساب عام؛ تُنشأ الحسابات عبر Supabase Auth ويُسند الدور والمدرسة من إجراء إداري موثوق. لا تضع كلمات المرور أو مفاتيح الخدمة داخل المستودع أو متغيرات الواجهة العامة.

### خطوات التفعيل قبل استخدام الموقع
1. أنشئ مشروعًا في Supabase أو اختر المشروع المعتمد لديك.
2. من SQL Editor شغّل الملف `supabase/schema.sql` لإنشاء المدارس والملفات الشخصية وأعمال الملف المهني وسياسات RLS. يجب تنفيذ SQL داخل مشروع Supabase يدويًا؛ تحديث GitHub لا ينفذه تلقائيًا في قاعدة البيانات.
3. أضف بيانات المدارس إلى `public.schools`، ثم أنشئ المستخدمين من Authentication في Supabase.
4. لكل مستخدم مدرسي، أضف صفًا في `public.profiles` يكون `id` هو UUID نفسه للمستخدم في Auth، مع الاسم ورقم المدرسة و`school_id` والدور المناسب. حساب `super_admin` العام لا يحتاج إلى ربطه بمدرسة؛ اترك `school_id` و`school_number` بقيمة NULL له.
5. أضف إلى متغيرات البيئة في مشروع Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` (أو مفتاح publishable المتاح في مشروعك)
6. أعد نشر الموقع. من دون هذه المتغيرات سيُحوّل الموقع الزائر إلى صفحة إعداد المصادقة بدل السماح بالدخول.

### الأدوار
- `teacher`: معلم
- `counselor`: مرشد
- `deputy_principal`: نائب مدير
- `principal`: مدير مدرسة
- `admin`: إداري المدرسة (ضمن نطاق المدرسة)
- `super_admin`: المسؤول الأعلى، بصلاحيات شاملة عبر جميع المدارس

يجب ألا يُمنح أي شخص دورًا إداريًا من الواجهة العامة. لا تستخدم مفتاح `service_role` في متغيرات تبدأ بـ `NEXT_PUBLIC_` أو في المتصفح.

## ملاحظات مهمة
- جدول `portfolio_works` وسياسات RLS الخاصة به أصبحا معرفين في المخطط. الواجهة الحالية ما زالت تعرض بيانات تجريبية ثابتة في أجزاء منها؛ تعريف الجدول لا يربط هذه البطاقات تلقائيًا بقاعدة البيانات.
- سياسات المدارس والملفات الشخصية مضمّنة في SQL، بما فيها دور نائب المدير وصلاحيات المسؤول الأعلى. هذه السياسات تخص جداول المدارس والملفات الشخصية فقط؛ يجب إضافة سياسات RLS مستقلة لكل جدول أعمال/إنجازات قبل تخزين بيانات حقيقية، ثم اختبار فصل المدارس عمليًا.
- ملف `.env.example` يوضح أسماء متغيرات البيئة المطلوبة.
